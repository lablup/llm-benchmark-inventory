# 벤치마크별 추천 모델 조사 기록

확인일: 2026-09-26

벤치마크 카드의 "추천 모델" 블록은 각 벤치마크에서 점수가 높은 모델을 상위 3개까지 보여줍니다. 모든 점수에 출처와 기준일, 확인일을 적었습니다. 데이터는 `benchmark_top_models.csv`에 있고, `build_site_data.rb`가 카드에 붙입니다.

## 무엇을 보여주는가

- **전체**: 출처 표 안에서 점수가 높은 모델 1~3위. 동점은 함께 적습니다.
- **공개 가중치(로컬 실행 가능)**: 같은 표 안에서 가중치를 내려받아 로컬에서 실행할 수 있는 모델만 골라 1~3위. Hugging Face나 공식 저장소에 가중치가 있는 모델만 `open_weight = true`로 표시했습니다. API로만 쓰는 모델은 `false`입니다.
- **모델 링크**: 공개 가중치 모델은 Hugging Face 모델 페이지(없으면 공식 GitHub), 상용 모델은 제공사의 모델 문서 페이지입니다. 현재 문서에서 사라진 옛 모델은 제공사의 지원 종료(deprecations) 페이지로 연결했습니다. 링크는 실제로 열어 응답과 모델 이름을 확인한 것만 실었습니다.
- **출처**: 리더보드 또는 논문 링크, 스냅숏 기준일, 확인일. 지표와 설정(few-shot 수, 채점 방식 등)을 함께 적습니다.

## 출처를 고른 순서

1. 벤치마크 저자가 운영하는 공식 리더보드(사이트, GitHub README 결과표, 데이터 카드의 결과표).
2. 논문 최신판의 본문 결과표. PDF를 내려받아 표의 숫자를 텍스트로 확인했습니다.
3. 저자 리더보드가 없고 논문 표에 2025년 이전 모델만 있을 때는, 한 곳에서 같은 프로토콜로 여러 모델을 재는 제3자 리더보드(Epoch AI Benchmarking Hub, Stanford HELM, Hugging Face Open LLM Leaderboard 아카이브, EvalPlus, MathArena, Vals.ai 등)를 썼고 카드에 "제3자 리더보드"로 표시했습니다.
4. 모델 벤더가 각자 보고한 수치를 모아 순위를 만들지 않았습니다. 설정이 서로 달라 비교할 수 없기 때문입니다.

한 벤치마크의 순위는 언제나 한 출처, 한 설정 안에서만 매겼습니다. 1차 출처 표에 공개 가중치 모델이 없거나 하나뿐인 벤치마크는 공개 가중치 목록만 다른 출처에서 가져오고, 카드에 그 출처를 따로 표시하며 두 목록의 점수를 서로 비교하지 않는다고 적었습니다.

## 상태 표시

- **확인(verified)**: 출처 표를 직접 읽어 숫자를 확인했습니다.
- **일부 확인(partial)**: 출처는 있으나 2025년 이전 모델만 있거나, 표가 이미지뿐이어서 일부만 읽었거나, 설정이 섞여 있어 일부 열만 썼습니다. 카드에 "일부 확인"이 붙습니다.
- **미확인(unverified)**: 어디에도 모델 점수가 없습니다. 카드에 추천 모델 블록이 없습니다. 해당: KorMedLawQA, korean-legal-qa, KR-Legal-QA, AIME2025-ko, Ko-TruthfulQA.

## 읽을 때 주의할 점

- 갱신이 멈춘 보드가 많습니다. BFCL(2026-04), BigCodeBench(2025-04), KOFFVQA(2025-05), LogicKor(2024-10), MT-Bench(2024 중반), EvalPlus(2024-12), HELM Lite(2025-01). 카드의 기준일을 함께 보십시오.
- 공식 보드는 벤더 자기 보고보다 낮은 경우가 있습니다. SWE-bench Verified 공식 보드는 2026-02 이후 제출이 없고 운영진이 확인한 최고치는 74.4입니다.
- 벤치마크 버전이 갈린 경우가 있습니다. Terminal-Bench 사이트는 4.0 결과만 제공하고, FrontierMath는 v2가 v1을 대체했습니다. SimpleQA의 공개 가중치 목록은 Google이 교정한 "SimpleQA Verified" 부분집합 기준입니다.
- 낮을수록 좋은 지표는 오름차순입니다. KSAFE-MM은 공격 성공률(ASR), HalluLens는 환각률입니다. KSAFE-MM에서 1위 모델은 거부율도 가장 높습니다.
- 에이전트 제출물이 섞인 보드(OSWorld, SWE-bench Verified, GAIA, Terminal-Bench)는 프레임워크와 순수 모델이 함께 순위에 오릅니다. 카드의 설정 문구에 조건을 적었습니다.
- 몇몇 한국어 벤치마크(CSAT-QA, PAWS-X ko, KorNLI 원표, KOLD, KoBEST 원표, CLIcK, Belebele ko)는 2019~2023년 모델만 평가한 표가 유일하거나, 2025년 표로 대체했습니다. 대체한 경우 옛 값은 조사 기록의 비고에 남겼습니다.

## 조사 방법의 한계

- 인벤토리 88개 벤치마크를 2026-09-26 하루에 조사했습니다. 이후 갱신된 보드는 반영되지 않았습니다.
- JavaScript로만 그려지는 보드는 페이지가 불러오는 데이터 파일(CSV, JSON, xlsx)을 직접 읽었습니다. 방법은 조사 기록에 있습니다.
- 공개 가중치 여부는 Hugging Face 저장소 존재로 판정했습니다. 라이선스가 비상업이어도 가중치가 공개되어 있으면 `true`입니다. 실제 이용 전에 모델 라이선스를 확인해야 합니다.
