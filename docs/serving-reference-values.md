# 서빙 보드별 대표 측정값 조사 기록

확인일: 2026-09-26

서빙·자원 인벤토리의 "공개 성능 표준·보드" 카드에는 **대표 측정값** 3개가 붙습니다. 능력 벤치마크의 추천 모델과 다른 점은, 서빙 수치가 모델 하나가 아니라 **모델 + 하드웨어 + 엔진(버전·정밀도) + 부하 조건**의 묶음에 붙는다는 것입니다. 같은 모델이라도 가속기, 엔진, 동시 요청 수, 입력·출력 길이, 지연 한계가 다르면 초당 토큰 수가 몇 배씩 달라집니다. 그래서 각 행에 조건을 함께 적었고, 조건이 빠진 숫자는 싣지 않았습니다. 데이터는 `serving_reference_values.csv`에 있고 `build_site_data.py`가 카드에 붙입니다.

## 무엇을 보여주는가

- 한 보드의 3개 행은 같은 라운드(또는 스냅숏), 같은 모델, 같은 시나리오 안에서 뽑았습니다. 라운드나 시나리오가 다른 값은 섞지 않았습니다.
- 행마다 시스템 또는 제공자 이름, 모델, 하드웨어(가속기 종류·수), 엔진(소프트웨어·버전·정밀도), 부하 조건, 지표와 값을 적었습니다. 가속기 1개당 값을 계산할 수 있으면 함께 적었습니다.
- 낮을수록 좋은 지표(TTFT, TPOT)는 오름차순, 높을수록 좋은 지표(초당 토큰)는 내림차순입니다. 패널 제목에 방향을 표시했습니다.
- 출처는 보드가 공개한 원시 결과 파일(제출 결과 저장소, 결과 표 CSV, 페이지가 불러오는 JSON)을 우선했고, 기준일과 확인일을 적었습니다.

## 보드별 성격

- **MLPerf Inference**: 워크로드와 지연 한계를 고정하고 제출자가 자기 시스템으로 낸 처리량을 공개합니다. 비교 단위는 모델이 아니라 시스템 제출이라, 같은 GPU라도 제출자마다 구성(가속기 수, 소프트웨어)이 다릅니다.
- **MLPerf Endpoints**: 배포된 추론 엔드포인트를 같은 방법으로 잰 결과입니다.
- **InferenceX**: 같은 모델을 GPU × 엔진 조합마다 돌려 처리량 대 응답성(interactivity)의 파레토 곡선으로 공개합니다. 자체 호스팅 환경 비교에 가깝습니다.
- **Artificial Analysis Performance**: 상용 API 제공자별 수치입니다. 제공자의 배치와 부하 상황이 섞여 있어 자체 호스팅 수치와 직접 비교할 수 없습니다.
- **OpenBenchmarks Inference**: 같은 모델의 여러 API를 과제 성공률과 함께 잰 보고서입니다.

## 상태 표시

- **확인(verified)**: 원시 결과 파일이나 결과 표를 직접 읽어 숫자를 확인했습니다.
- **일부 확인(partial)**: 읽을 수 있는 범위가 일부이거나 조건 일부가 공개되지 않았습니다. 카드에 "일부 확인"이 붙습니다.
- **미확인(unverified)**: 결과가 표로 공개되어 있지 않습니다. 카드에 대표 측정값 블록이 없습니다.

## 읽을 때 주의할 점

- 라운드마다 워크로드와 지연 한계가 바뀝니다. 다른 라운드의 값과 비교하지 마십시오.
- 가속기 1개당 값은 시스템 설명의 가속기 수로 나눈 것이며, 노드 간 통신이나 CPU 기여를 반영하지 않습니다.
- API 제공자 수치는 측정 시점의 부하와 제공자의 배치에 따라 달라지며, 자체 호스팅 성능을 뜻하지 않습니다.
- 조사 원자료(보드별 JSON, 내려받은 결과 파일의 SHA-256, 조사 보고)는 Benchpress 저장소 `refer/benchmark_scores/`에 있습니다.
