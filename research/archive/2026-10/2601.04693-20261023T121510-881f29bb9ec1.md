## 미반영 사유

Claude가 근거 부족으로 반영을 승인하지 않았습니다: 거절합니다. 벤치마크 자체의 사실(문항 수 4,784, train 2,500/validation 1,000/test 1,284, 선택지 4종 구성, 평가 방식)과 권리 필드는 논문과 공식 카드로 대체로 뒷받침됩니다. 데이터셋 라이선스 CC BY-NC-SA 4.0은 논문 10쪽에 근거가 있고, 공식 저장소의 Apache-2.0 파일은 코드용으로 올바르게 구분했습니다. 상업적 이용 불가, 수정·파생 가능(동일조건), 재배포 조건부 가능도 이 라이선스와 맞습니다. 한국어 위키백과와 OpenAI API 생성 선택지를 언급하고 각 구성 요소 약관을 별도로 확인하라고 안내한 점, 공식 README에 lm-eval 태스크 설치 안내가 있어 lm-eval 지원 서술이 뒷받침되는 점도 문제 없습니다. 다만 다음 이유로 게시할 수 없습니다. (1) 이용 시 유의사항이 위키백과 크롤링과 모순·바꿔 쓰기 선택지의 OpenAI API 초안 생성을 논문 4쪽 내용으로 인용했는데, 실제 해당 서술은 6쪽(구축 절차)에 있어 쪽수 인용이 사실과 다릅니다. (2) 추천 목록이 선택한 실험(Table 16의 0-shot symbol)의 비교 대상 모델 전체를 포함하지 않습니다. 모델명이 두 줄로 나뉜 12개 행(Midm-2.0 두 종, kanana-1.5 instruct 두 종, HyperCLOVAX-SEED 세 종, SOLAR-Instruct, Mistral-Nemo 두 종, Mistral-Small 두 종)을 제외했습니다. 제외 행의 점수가 모두 상위 3개보다 낮아 순위 자체는 바뀌지 않는 것으로 보이지만, 목록이 비교 대상 전체를 덮어야 상위 3개 선정이 정당화된다는 기준을 충족하지 못합니다. 이는 표 추출 한계가 아니라 Poppler 텍스트로 값을 확인할 수 있는 행의 누락입니다. (3) 같은 열에 로그우도 기반 acc(오픈 모델)와 API 모델의 exact\_match가 섞여 있습니다. 설정 설명에 밝히긴 했지만 지표가 동일하지 않은 모델을 한 순위에 올리는 것은 정당화가 부족합니다. (4) 일부 수치는 다른 표와 반올림 수준으로 어긋납니다. 예를 들어 Qwen3-14B의 symbol 점수는 Table 16과 Table 21에서 서로 다르게 읽힙니다. 위 문제를 고치고 누락 모델을 포함해 다시 제출하면 재검토할 수 있습니다.

이 사유는 당시 자동 조사 기록이며, 논문 자체의 부적합을 확정하는 판단이 아닙니다.
