# An open benchmark for machine learning-based polymer property prediction

- 논문: https://arxiv.org/abs/2609.27036
- 조사 시각: 2026-10-27 12:04:04 (한국 시간)

- 1차 추출 모델: claude-sonnet-5-5

## 미반영 사유

PolyBench26은 고분자 반복 단위를 PSMILES 문자열이나 분자 그래프로 입력받아 물성(Tg, 밀도, 굴절률 등)을 회귀 예측하는 재료·화학 ML 벤치마크입니다. 한국어나 영어 과제·지시문을 평가하는 LLM 벤치마크가 아닙니다. 주 평가 대상은 그래프 신경망과 기술자 기반 모델이고, GPT-4o와 GPT-o3-mini는 Task 1에서 zero-shot 비교군으로만 쓰였으며 이후 Task 2~4에서는 제외됐습니다. 영어 프롬프트는 보충 자료에 있는 부수적 평가용이며 벤치마크의 과제 언어를 규정하지 않습니다. 따라서 인벤토리 범위(한국어·영어 과제 기반 LLM 평가)에 해당하지 않아 제외합니다.

이 사유는 당시 자동 조사 기록이며, 논문 자체의 부적합을 확정하는 판단이 아닙니다.
