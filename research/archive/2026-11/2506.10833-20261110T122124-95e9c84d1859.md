## 미반영 사유

SELU의 데이터 라이선스를 공급된 자료만으로는 확정할 수 없어 게시를 보류한다. 공식 README 카드에는 '\#\# LICENSE file' 절이 있고 MIT가 표기되어 있으므로 '미표기' 형태의 부재 증거는 쓸 수 없다. 반대로 이 MIT를 데이터셋 라이선스로 인용할 수도 없다. 카드 본문은 이 저장소를 'Source code to replicate the results'로 설명하며, LICENSE 파일은 저작권자 Fabian Peña의 소프트웨어에 대한 것이다. 반면 SELU는 새로 만든 데이터가 아니라 문헌에서 수집한 기존 공개 데이터셋 22개를 묶은 벤치마크다(논문 3쪽 'Task Selection', 4쪽 Table I의 출처 \[30\]–\[48\]). 이 구성 요소 각각에 MIT나 다른 단일 라이선스가 적용된다는 근거는 카드와 PDF 어디에도 없다. 코드 라이선스를 데이터 라이선스로 가정하는 것은 허용되지 않는다. 따라서 라이선스, 상업적 이용, 수정·파생, 재배포 네 항목에 필요한 증거(문서화된 값 또는 유효한 부재 증거)를 갖출 수 없다. 22개 구성 데이터셋 각각의 라이선스 또는 저자의 명시적 데이터 라이선스 문구를 확보해야 한다. lm-eval 지원은 카드와 PDF가 lm-eval을 언급하지 않아 '미표기' 부재 증거로 처리할 수 있고, 추천 결과는 논문 Table IV(8쪽)의 평균 성능으로 구성할 수 있다. 그러나 라이선스 증거가 없으면 게시할 수 없어 changes는 비워 둔다.

이 사유는 당시 자동 조사 기록이며, 논문 자체의 부적합을 확정하는 판단이 아닙니다.
