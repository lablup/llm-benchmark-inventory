## 미반영 사유

공식 저장소 README의 License 절은 "The code in this repository is released under the \*\*MIT License\*\*."라고 코드에만 MIT를 부여하고, GQA 이미지와 주석은 GQA 이용약관을, 추론 체인은 Anthropic 이용 정책을 따른다고 적습니다. 이는 코드 라이선스이며 SpatialChain 데이터셋 자체의 라이선스, 상업적 이용, 수정·파생, 재배포 조건을 밝힌 문장이 아닙니다. 논문 PDF 29쪽 전체에도 데이터 라이선스 문장이 없습니다. 이 데이터셋은 GQA(논문 2쪽 3.1절)와 Claude Haiku 4.5가 생성한 체인(논문 3쪽 3.3절)으로 구성되므로 모든 구성 요소에 적용되는 단일 데이터 라이선스를 확정할 수 없습니다. 카드에 라이선스 문장이 있어 '카드에 라이선스 없음'을 근거로 한 부재 증거(absent)도 쓸 수 없고, '저작권 전부 보유'로 기록하는 것도 허용되지 않습니다. 데이터 라이선스가 적혀 있을 가능성이 큰 Hugging Face 데이터 카드(spatialchain/SpatialChain-Benchmark)는 이번에 제공되거나 조회되지 않았습니다. lm-eval은 README와 PDF 어디에도 언급되지 않아 '미표기'와 부재 증거로 처리할 수 있으나, 라이선스 관련 네 항목이 증거 없이 남으므로 게시할 수 없습니다. 기존 초안의 '확인 불가' 값은 게시 정책에 위배되어 폐기합니다. Hugging Face 데이터 카드를 확인해 데이터 라이선스와 이용 조건이 명시되는지 본 뒤 다시 제출해 주세요.

이 사유는 당시 자동 조사 기록이며, 논문 자체의 부적합을 확정하는 판단이 아닙니다.
