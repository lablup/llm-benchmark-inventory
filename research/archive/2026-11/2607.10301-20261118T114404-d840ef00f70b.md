## 미반영 사유

ChartSync의 데이터 라이선스를 뒷받침할 근거가 제공되지 않아 게시를 보류합니다. 공식 저장소 README는 'The source code in this repository is released under the Apache License 2.0'라고 적어 Apache-2.0을 소스 코드에만 부여하고, LICENSE 파일(Apache-2.0)도 코드에 대한 것입니다. 코드 라이선스는 데이터셋 라이선스가 아닙니다. 벤치마크 데이터는 README가 안내하는 Hugging Face 저장소(JiakangYu/ChartSync)에 별도로 배포되는데, 이 데이터 카드는 공급된 공식 자료에 없어 데이터에 적용되는 라이선스와 상업적 이용·수정·파생·재배포 조건을 가져오지 못했습니다. 이 저장소 카드에는 '\#\# LICENSE file' 섹션이 있으므로 '미표기' 부재 증거로 대체할 수 없습니다. 또한 PDF 4쪽에 따르면 원본 차트 이미지와 렌더링 코드는 ChartMimic에서 가져왔으므로 구성 요소별 약관도 함께 점검해야 합니다. 이 상태에서는 5개 필드 중 라이선스, 상업적 이용, 수정·파생, 재배포를 근거와 함께 채울 수 없어 changes를 비우고 반환합니다. Hugging Face 데이터 카드(https://huggingface.co/datasets/JiakangYu/ChartSync)의 원문을 공급해 주시면 다시 작성하겠습니다.

이 사유는 당시 자동 조사 기록이며, 논문 자체의 부적합을 확정하는 판단이 아닙니다.
