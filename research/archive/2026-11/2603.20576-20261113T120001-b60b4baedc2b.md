## 미반영 사유

DAB 행을 공개하려면 라이선스, 상업적 이용, 수정·파생, 재배포 네 항목에 명시적 근거가 있어야 하는데, 수정·파생과 재배포는 PDF와 공식 저장소 카드 어디에도 해당 조건을 직접 밝힌 문구가 없고, 상업적 이용도 문구가 간접적이라 게시할 수 없습니다. (1) PDF 10쪽 윤리 절에 "We release DAB's transformation scripts, validation scripts, and evaluation code under the MIT license; the transformed datasets are released for research use only, consistent with the licenses of their underlying sources."라는 문장이 있습니다. 이 문장은 코드에는 MIT를 부여하지만 코드 라이선스는 데이터 라이선스가 아닙니다. 데이터에 대해서는 연구용 한정이라는 제한만 밝힐 뿐 수정·파생이나 재배포 허용 여부를 말하지 않으며, 상업적 이용 불가라고도 명시하지 않았습니다. 이 문장이 데이터셋 자체의 이용 범위를 언급하므로 '미표기(논문·공식 저장소 확인)'와 '저작권 전부 보유' 방식의 부재 증거로 처리할 수 없고, 수정·파생과 재배포를 직접 인용할 구절도 없습니다. (2) 이 벤치마크는 다른 데이터에서 만들어졌습니다. PDF 4쪽에 따르면 17개 데이터셋 중 agnews, crmarenapro, imdb, krama는 기존 벤치마크에서 가져왔고 나머지 14개는 공개 데이터 저장소에서 가져왔는데, 14개 각각의 출처와 약관은 PDF에 열거되어 있지 않아 구성 요소별 이용 조건을 증명할 수 없습니다. (3) 공식 저장소 README 카드(https://github.com/ucbepic/DataAgentBench)에는 라이선스 문구나 LICENSE 파일 절이 없어 데이터 라이선스를 직접 인용할 곳이 없습니다. 저자가 데이터셋의 라이선스(수정·파생, 재배포, 상업적 이용 조건과 구성 요소별 적용 범위)를 저장소나 논문에 명시하면 그 문구를 인용해 다시 제안할 수 있습니다. 성능 비교(논문 표 3)는 근거가 있으나, 권리 항목이 비어 있어 이번에는 아무것도 게시하지 않습니다.

이 사유는 당시 자동 조사 기록이며, 논문 자체의 부적합을 확정하는 판단이 아닙니다.
