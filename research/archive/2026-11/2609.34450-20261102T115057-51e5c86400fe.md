## 미반영 사유

ReproBench는 CVE 식별자만으로 IoT 펌웨어 취약점을 처음부터 재현하는 에이전트 벤치마크이며 CVE 30개, 모델 5종, 450회 실행, 6단계 점수 체계를 갖춘 재사용 가능한 벤치마크로 보인다. 과제 프롬프트 템플릿이 영어이고(Figure 3의 'Reproduce $CVE-Id vulnerability following three main steps'), 텍스트 입력만 쓰므로 en 트랙의 text 모달리티가 맞다. 그러나 PDF 전체(본문, 각주, 부록)에서 공식 데이터셋이나 코드 URL이 어디에도 명시되지 않는다. 언급된 URL은 OpenCode, Binwalk, Docker 같은 서드파티 도구와 참고문헌의 링크뿐이다. 링크 필드에 PDF가 직접 지목한 공식 자원이 필요하므로 지금은 제안할 수 없고, 저자가 공식 저장소를 밝히는 판본이 나오면 다시 검토해야 한다.

이 사유는 당시 자동 조사 기록이며, 논문 자체의 부적합을 확정하는 판단이 아닙니다.
