## 미반영 사유

데이터셋 라이선스에 대한 근거 문서가 공급되지 않아 게시할 수 없다. 공식 GitHub 카드의 MIT는 README 'Original MEA-Bench code and documentation are licensed under the MIT License'와 LICENSE 파일이 밝히듯 원 코드와 문서에만 적용된다. 같은 카드는 제3자 코드, 데이터셋, 모델 가중치가 각자의 상위 라이선스와 약관을 유지하며 MIT가 이를 재라이선스하지 않는다고 밝힌다. 이 벤치마크의 질의 풀은 별도 Hugging Face 데이터셋(watermarkproject/lord-mea-benchmark)으로 배포되는데 그 데이터 카드는 공급되지 않았다. 질의 풀은 LMSYS-Chat-1M, NuminaMath-CoT, TriviaQA, MMLU, GSM8K 등 기존 데이터에서 입력만 가져와 구성했고(논문 6쪽, 20쪽), 평가 과제도 기존 벤치마크다(논문 20쪽). 코드 라이선스를 데이터셋 라이선스로 간주할 수 없다. 카드에는 LICENSE 파일 항목이 있어 라이선스 미표기를 근거로 한 '저작권 전부 보유' 처리도 쓸 수 없다. 따라서 라이선스, 상업적 이용, 수정·파생, 재배포 네 항목 모두 정책이 요구하는 명시적 근거를 제시할 수 없다. 기존 초안의 해당 칸 값은 게시 정책에 맞지 않으므로 사용하지 않는다. 질의 풀 데이터셋 카드를 공식 자료로 추가로 가져온 뒤 다시 제안해야 한다.

이 사유는 당시 자동 조사 기록이며, 논문 자체의 부적합을 확정하는 판단이 아닙니다.
