## 분야 구분

- **한국어·영어 벤치마크**는 모델 능력(model capability)을 평가하는 데이터셋과 실행 도구를 다룹니다.
- **서빙·자원**은 지연 시간과 처리량을 재는 도구, 공개 성능 비교, GPU·엔진 계측을 다룹니다.
- 점수는 출처와 확인일을 함께 적습니다. 벤치마크 카드의 **추천 모델**은 한 출처·한 설정 안에서 점수가 높은 모델 3개와 공개 가중치(open-weight) 모델 3개를 점수, 모델 링크, 출처 링크, 기준일과 함께 보여줍니다. 서빙·자원 자료는 공식 방법론과 결과 페이지를 연결하고 재현 조건과 운영 상태를 기록하며, 공개 성능 표준·보드 카드에는 모델·하드웨어·엔진·부하 조건을 함께 적은 **대표 측정값** 3개를 실었습니다. 조사 방법과 한계는 [벤치마크별 추천 모델 조사 기록](./docs/recommended-models.md)에 있습니다.
- 자동 논문 조사가 어떤 논문을 시도했고 어디서 멈췼는지(PDF 추출 실패, 초안 거부, 근거 부족 보류, 제외, 표 반영)는 [조사 현황](https://lablup.github.io/llm-benchmark-inventory/papers.html#research)에서 논문별로 볼 수 있고, 하루 한 줄 요약은 GitHub의 `research-log` 라벨 이슈에 댓글로 쌓입니다.
- 서빙·자원 표는 자동으로 바뀌지 않습니다. 대신 매일 감시기가 각 도구·보드의 새 릴리스, 커밋, 페이지 변경을 기록하고 이슈로 알립니다. 방식은 [서빙·자원 감시 기록](./docs/serving-watch.md)에 있습니다.

## 읽는 방법

- **상업적 이용**은 데이터 카드 등에 표시된 라이선스를 기준으로 `가능`, `불가`, `조건 확인 필요`, `저작권 전부 보유`, `확인 불가`의 다섯 가지로 구분합니다.
- `저작권 전부 보유`는 논문·데이터 카드·공식 저장소를 확인했는데 라이선스가 적혀 있지 않은 경우(라이선스 열 `미표기`)입니다. 라이선스가 없는 공개물은 저작권 전부 보유(all rights reserved) 상태로 간주해 상업적 이용·수정·파생·재배포를 모두 불가로 봅니다. 이용하려면 저자에게 직접 확인해야 합니다.
- `확인 불가`는 비공개 저장소 등으로 라이선스 확인 자체를 하지 못한 경우(라이선스 열 `확인 불가`)이며 다시 조사할 대상입니다. `미확인`, `unknown` 같은 표기는 쓰지 않습니다.
- 라이선스는 2026-09-26에 각 데이터 카드와 저장소에서 확인했습니다. 이후 바뀔 수 있으므로 실제 이용 전에 원문을 다시 확인해야 합니다.
- **대표 예시**는 각 벤치마크의 실제 과제 문항입니다. 영어 벤치마크는 한국어 번역이나 요약을 제공하는 경우가 많으며, CSV의 `예시 표기` 열에서 영문 예시와 한국어 요약을 구분합니다. 자동 조사가 실제 문항 대신 과제 설명을 적은 행은 `과제 설명`으로 표시합니다.
- `lm-eval 지원`은 오픈소스 평가 프레임워크 [lm-evaluation-harness](https://github.com/EleutherAI/lm-evaluation-harness)(EleutherAI)에 해당 과제가 내장되어 있는지를 뜻합니다. 조사 시점 기준이며 최신 버전에서는 달라질 수 있습니다.

## 기여 시 확인 사항

1. 데이터 카드와 공식 저장소의 라이선스를 우선 확인
2. 데이터 라이선스와 코드·평가 하니스 라이선스를 구분
3. 번역본·미러·수집물은 원본 라이선스가 자동 승계된다고 가정하지 않기
4. 라이선스 재확인 시 문서 상단의 확인 기준일을 갱신
5. 어디에도 라이선스가 없으면 `라이선스` 열에 `미표기(확인한 곳)`를, 확인하지 못했으면 `확인 불가`를 적기. `미확인`·`unknown`은 쓰지 않기. `상업적 이용`·`수정·파생`·`재배포` 열은 `build_benchmark_inventory.py`가 채움
